# Screenshots

Drop your PaySentinel dashboard screenshots here with these exact filenames:

- `dashboard.png` — Portfolio health metrics page (`/dashboard`)
- `simulator.png` — Recovery agent simulator (`/simulator`)
- `approvals.png` — Human approval queue (`/approvals`)
- `cases.png` — Payment cases list (`/cases`)

Then run:
```bash
git add docs/images/screenshots/
git commit -m "docs: add dashboard screenshots"
git push origin main
```
